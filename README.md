# FixMe

**Robust Pose Estimation for Home Workouts** – project proposal by Hila Tati and Avshalom Habani
(LLMs and Agents course, Holon Institute of Technology).

FixMe gives real-time exercise form feedback from a phone lying on the floor. We test whether
fine-tuning a pose model on low-angle, occluded home-workout video improves keypoint accuracy and
the feedback a trainee gets, compared with off-the-shelf models such as MediaPipe.
